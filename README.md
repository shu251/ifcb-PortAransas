# ifcb-PortAransas

Port Aransas Imaging FlowCytobot (IFCB) time series (2007–2017): data wrangling, environmental-regime classification, diel and co-occurrence analysis, and manuscript planning for the "beyond phytoplankton" heterotroph/mixotroph project.

## Top-level files

- `_quarto.yml` — Quarto project config for rendering the `.qmd` notebooks in this folder.
- `ifcb-analysis-PortAransas.Rproj` — RStudio project file; open this to work in the project.
- `LICENSE` — MIT license (S. K. Hu, 2026).
- `README.md` — this file.
