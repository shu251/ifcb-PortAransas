2.1 Temperature & Salinity

Import from TABS D manual pull of data.

The raw file has 1,084 exact duplicate rows (dropped below with distinct()). It also has ~13,000 timestamps with two different temp/salinity readings for the same hour (e.g. 2012-04-09 08:00 has both 23.8C/33.9 psu and 24.9C/26.9 psu on record) — a real discrepancy, likely two overlapping sensor deployments or data pulls spliced together, not a parsing artifact. That’s left unresolved here (flagged as a follow-up); it gets arbitrarily collapsed to one reading per hour later, in hourly_metadata.

Subtract tide height from previous entry to see if tide is incoming or outgoing.

Code 
tide_height_df <- tide_height %>% 
  mutate(DATE_TIME = ymd_hm(timestamp),
         MONTH = month(DATE_TIME),
         DAY = day(DATE_TIME),
         HOUR = hour(DATE_TIME),
         MIN = minute(DATE_TIME),
         DATE = date(DATE_TIME)) %>% 
  filter(MIN == 0) %>% # Sample only on the hour or at 30 minutes.
  mutate(DIFFERENCE = MLLW - lag(MLLW, default = first(MLLW))) %>% 
  mutate(tide_direction = case_when(
      DIFFERENCE > 0 ~ "Incoming",
      DIFFERENCE < 0 ~ "Outgoing",
      TRUE ~ "No Change"
    )) %>% 
  select(DATE, MONTH, DAY, HOUR, MIN, MLLW, DIFFERENCE, tide_direction)

tide_height_df <- tide_height %>% 
  mutate(DATE_TIME = ymd_hm(timestamp),
         MONTH = month(DATE_TIME),
         DAY = day(DATE_TIME),
         HOUR = hour(DATE_TIME),
         MIN = minute(DATE_TIME),
         DATE = date(DATE_TIME)) %>% 
  filter(MIN == 0) %>% # Sample only on the hour or at 30 minutes.
  mutate(DIFFERENCE = MLLW - lag(MLLW, default = first(MLLW))) %>% 
  mutate(tide_direction = case_when(
      DIFFERENCE > 0 ~ "Incoming",
      DIFFERENCE < 0 ~ "Outgoing",
      TRUE ~ "No Change"
