2 Preliminary input data

All data from Port Aransas. Counts by hour. Remove data before January 1 2008, as it was newly deployed and has some inconsistencies. Also using lubridate to convert to R-friendly date/time formats. Note that Hurricane Harvey destroyed the pier housing the IFCB, so data stop right when Harvey was hitting the coastline.

Time zone is UTC and units of carbon are pg C per cell.

Code 
# head(counts)
counts <- read.csv("input-ifcb-data/counts_hourly_Hu.csv") |>  
  # Use lubridate package to assign "date" format.
  mutate(DAY = ymd_hms(X)) %>% 
  mutate(DATE = date(DAY),
         MONTH = month(DAY),
         HOUR = hour(DAY),
         MIN = minute(DAY)) %>% 
  select(DAY, DATE, MONTH, HOUR, MIN, everything(), -X) %>% 
  filter(as_date(DAY) >= as_date("2008-01-01") & 
           as_date(DAY) <= as_date("2017-08-24"))

Seasons

  • Cool : Dec-Feb, cold fronts add low temperatures and stronger mixing from wind.
  • Spring freshening : Mar-June, start seeing increased rain, and therefore lower salinity values, increased nutrients and increased riverine height.
  • Hot Hypersaline : Lower inflow from rivers, drought-risk season, high evaporation, warm, stratified conditions start emerging. Increased salinity. July-sept
  • Autumn low-inflow : Oct-Nov, increased salinity continues into the Fall, but temperatures start declining. water column usually remains stratefied, some major storms will arise and add punctuated mixing.

**Seasons**

* _Cool_ : Dec-Feb, cold fronts add low temperatures and stronger mixing from wind. 
* _Spring freshening_ : Mar-June, start seeing increased rain, and therefore lower salinity values, increased nutrients and increased riverine height.
* _Hot Hypersaline_ : Lower inflow from rivers, drought-risk season, high evaporation, warm, stratified conditions start emerging. Increased salinity. July-sept
* _Autumn low-inflow_ : Oct-Nov, increased salinity continues into the Fall, but temperatures start declining. water column usually remains stratefied, some major storms will arise and add punctuated mixing.
